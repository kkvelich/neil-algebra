6.02 — Adding and Subtracting Polynomials

Combine like terms, distribute the minus carefully, and use function notation (f + g)(x). One trap (the minus sign) accounts for most missed problems — kill it here.

10 practice problems ~30 min Closure + (f±g)

A. Like terms

Two terms are like terms if they have the same variables raised to the same exponents. The coefficients can differ.

PairLike? Why
5x2   and   −3x2✅ Same variable, same exponent (2)
7xy   and   −2yx✅ Same variables, same exponents (order doesn't matter)
4x2   and   4x3❌ Different exponents on x
8x   and   8y❌ Different variables

B. Combining like terms

To combine like terms: add the coefficients, keep the variable part the same.

Example

5x2 + 3x2 = 8x2      7y − 2y = 5y      4ab + ab = 5ab

C. Adding polynomials

Drop the parentheses, line up like terms, add the coefficients.

Worked example

(3x3 + 5x − 2) + (x3 − 4x + 7)

  • Drop parens: 3x3 + 5x − 2 + x3 − 4x + 7
  • Group like terms: (3x3 + x3) + (5x − 4x) + (−2 + 7)
  • Combine: 4x3 + x + 5

D. Subtracting polynomials ⚠️ (the trap)

The single biggest mistake. When subtracting, you must distribute the negative to EVERY term in the second polynomial — not just the first one.
Worked example

(4x − 6) − (3x + 6)

  • Distribute the minus: 4x − 6 − 3x − 6 (the +6 became −6 ✓)
  • Combine: (4x − 3x) + (−6 − 6)
  • Answer: x − 12
Harder worked example

(6x2 + 2x3 − 3) − (4x3 − x2 + 5)

  • Distribute the minus: 6x2 + 2x3 − 3 − 4x3 + x2 − 5 (all three signs flip!)
  • Group: (2x3 − 4x3) + (6x2 + x2) + (−3 − 5)
  • Answer: −2x3 + 7x2 − 8
Watch the wording: "5x − 6 subtracted FROM 3x2 − 6x + 2" means (3x2 − 6x + 2) − (5x − 6), not the other way around.

E. Closure property

The closure property says: when you add OR subtract two polynomials, the result is ALWAYS another polynomial. (Same with multiplication. Division? Not always — that can create variables in the denominator.)

On a quiz: if the question asks "demonstrates that polynomials are closed under addition/subtraction," the right phrasing is "the result WILL be a polynomial" — not "may or may not be."

F. (f + g)(x) and (f − g)(x)

If you have two functions f and g, then:

  • (f + g)(x) = f(x) + g(x) — add the outputs.
  • (f − g)(x) = f(x) − g(x) — subtract the outputs (distribute the minus over g!).
  • (f + g)(a) = f(a) + g(a) — plug a into each, then add.
Worked example

If f(x) = 2x − 9 and g(x) = x2 + 3, find (f + g)(4).

  • f(4) = 2(4) − 9 = −1
  • g(4) = 42 + 3 = 19
  • (f + g)(4) = −1 + 19 = 18

G. Word problems

Perimeter (sum of side lengths)

Worked example

Rectangle: length x + 6, width y − 1. Perimeter?

P = 2·length + 2·width = 2(x + 6) + 2(y − 1) = 2x + 2y + 10.

Profit = Revenue − Cost (a subtraction)

Worked example

A tablet sells for f(x) = 3x + 6000 and costs g(x) = 20x − 400 to make. Find profit at x = 300.

  • f(300) = 3(300) + 6000 = $6,900 (revenue)
  • g(300) = 20(300) − 400 = $5,600 (cost)
  • Profit = (f − g)(300) = 6900 − 5600 = $1,300 profit
Trap: a (f − g) result represents profit (revenue minus cost), NOT cost. Read the question carefully.

Combining quantities (calories, time, distance)

Worked example

f(x) = 2x + 210 calories burned exercising for x hours. g(x) = 2x + 125 deficit from diet. Find (f + g)(3).

  • f(3) = 2(3) + 210 = 216
  • g(3) = 2(3) + 125 = 131
  • (f + g)(3) = 347 calories total — combining diet with 3 hours of exercise.

H. Practice (10 problems)

Problem 1

Simplify (4x − 6) + (5x + 1).

Show answer
9x − 5. 4x + 5x = 9x; −6 + 1 = −5.
Problem 2

Simplify (4x − 6) − (3x + 6).

Show answer
x − 12. Distribute the minus: 4x − 6 − 3x − 6 → (4x − 3x) + (−6 − 6) = x − 12.
Problem 3

Simplify (3x2 − 2) + (2x2 − 6x + 3).

Show answer
5x2 − 6x + 1. 3x2+2x2 = 5x2; −6x stays; −2+3 = 1.
Problem 4

Total distance: run 2x miles + cycle (x2 + 7) miles + swim (x − 2) miles. Simplify.

Show answer
x2 + 3x + 5. 2x + x2 + 7 + x − 2 → x2 + 3x + 5.
Problem 5

Total commute = (2x − 6y) + (6x − 10y).

Show answer
8x − 16y. 2x + 6x = 8x; −6y − 10y = −16y.
Problem 6

Rectangle: length 5x + 3, width 2x − 1. Find perimeter; what does closure say about the result?

Show answer
P = 14x + 4; the result IS always a polynomial. P = 2(5x+3) + 2(2x−1) = 10x + 6 + 4x − 2 = 14x + 4. Closure: sums of polynomials are always polynomials.
Problem 7

Subtract 5x − 6 FROM 3x2 − 6x + 2.

Show answer
3x2 − 11x + 8 (and the result IS a polynomial). (3x2 − 6x + 2) − (5x − 6) = 3x2 − 6x + 2 − 5x + 6 = 3x2 − 11x + 8.
Problem 8

Simplify (5x2 + 2x − 6) − (3x2 − 6x + 2).

Show answer
2x2 + 8x − 8. Distribute the minus: 5x2+2x−6 − 3x2+6x−2 → (5−3)x2 + (2+6)x + (−6−2) = 2x2 + 8x − 8.
Problem 9

f(x) = 3x − 5, g(x) = x2 + 2. Find (f + g)(3).

Show answer
15. f(3) = 4; g(3) = 11; sum = 15.
Problem 10

f(x) = 3x + 6000 (revenue), g(x) = 20x − 400 (cost). Find (f − g)(300) and explain.

Show answer
$1,300 PROFIT from 300 tablets. f(300) = 6900; g(300) = 5600; f − g = 1300. Revenue − cost = profit (not cost).

🔑 Key things to remember

  • Distribute the minus to EVERY term when subtracting — this is the #1 mistake. Both −(3x + 6) = −3x − 6 and −(4x3 − x2 + 5) = −4x3 + x2 − 5.
  • "A subtracted FROM B" = B − A, not A − B. Always.
  • Closure: sum or difference of polynomials is ALWAYS a polynomial.
  • (f + g)(a) = f(a) + g(a) — plug in first, then add.
  • Profit = revenue − cost — when a word problem subtracts two functions, name the result (profit, deficit, savings) — don't just say "cost."
