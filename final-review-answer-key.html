Simplify (add / subtract polynomials) — #1–4

1.(5p2 − 3) + (2p2 − 3p3)

Answer: −3p3 + 7p2 − 3
5p² + 2p² = 7p². Then drop in −3p³ and constant −3, write in standard form.

2.(−4k4 + 14 + 3k2) + (−3k4 − 14k2 − 8)

Answer: −7k4 − 11k2 + 6
k⁴: −4 + −3 = −7. k²: 3 + (−14) = −11. Constants: 14 + (−8) = 6.

3.(−4k4 + 14 + 3k2) − (−3k4 − 14k2 − 8)

Answer: −k4 + 17k2 + 22
⚠ Distribute the minus: = −4k⁴ + 14 + 3k² + 3k⁴ + 14k² + 8. Combine: k⁴: −4+3 = −1. k²: 3+14 = 17. Constants: 14+8 = 22.

4.(8n − 3n4 + 10n2) − (3n2 + 11n4)

Answer: −14n4 + 7n2 + 8n
Distribute minus: 8n − 3n⁴ + 10n² − 3n² − 11n⁴. n⁴: −3 − 11 = −14. n²: 10 − 3 = 7. n: 8.

Multiply (FOIL, special products, area) — #5–12

5.2(a + 1)(6a − 1)

Answer: 12a2 + 10a − 2
FOIL first: (a+1)(6a−1) = 6a² + 5a − 1. Then multiply by 2.

6.3(2a − 1)(8a − 5)

Answer: 48a2 − 54a + 15
FOIL: (2a−1)(8a−5) = 16a² − 10a − 8a + 5 = 16a² − 18a + 5. Times 3.

7.(2a + 3)2

Answer: 4a2 + 12a + 9
Perfect square: (2a)² + 2(2a)(3) + 3². ⚠ Don't drop the 12a middle term.

8.(3x + y)2

Answer: 9x2 + 6xy + y2
Perfect square: (3x)² + 2(3x)(y) + y².

9.(x − 2)(x + 2)

Answer: x2 − 4
Difference of squares — no middle term.

10.(x + 6)(x − 6)

Answer: x2 − 36
Difference of squares.

11.Rectangle area, sides 3x and (2x + 5)

Answer: 6x2 + 15x
3x(2x + 5) = 6x² + 15x.

12.Rectangle area, sides (4x − 1) and (6x + 9)

Answer: 24x2 + 30x − 9
FOIL: 24x² + 36x − 6x − 9 = 24x² + 30x − 9.

Factor trinomials — #26–30

26.x2 − 8x − 9

Answer: (x − 9)(x + 1)
Multiply to −9, add to −8 → −9 and +1.

27.2x2 − 5x − 3

Answer: (x − 3)(2x + 1)
AC = −6. Numbers: multiply to −6, add to −5 → −6 and +1. Split: 2x² − 6x + x − 3 → 2x(x−3) + 1(x−3).

28.2x2 + 3x − 2

Answer: (x + 2)(2x − 1)
AC = −4. Numbers: +4 and −1. Split: 2x² + 4x − x − 2 → 2x(x+2) − 1(x+2).

29.9x2 + 24x + 16

Answer: (3x + 4)2
Perfect square: (3x)² + 2(3x)(4) + 4² = 9x² + 24x + 16. ✓

30.4x2 − 4x + 1

Answer: (2x − 1)2
Perfect square: (2x)² − 2(2x)(1) + 1² = 4x² − 4x + 1. ✓

Solve quadratics — zero product + square root — #31–37

31.(x + 6)(x − 4) = 0

Answer: x = −6, x = 4

32.(2x + 5)(x − 3) = 0

Answer: x = −5/2, x = 3

33.x(x − 3)(2x + 1) = 0

Answer: x = 0, x = 3, x = −1/2
Three factors → three solutions.

34.(x − 3)2 + 1 = 13

Answer: x = 3 ± 2√3
Isolate: (x − 3)² = 12. ±√12 = ±2√3. So x − 3 = ±2√3 → x = 3 ± 2√3.

35.(2x − 5)2 − 4 = 20

Answer: x = (5 ± 2√6) / 2
(2x − 5)² = 24. 2x − 5 = ±√24 = ±2√6. 2x = 5 ± 2√6.

36.x2 = 36

Answer: x = ±6
⚠ Both ± — don't drop the negative.

37.x2 = 18

Answer: x = ±3√2
√18 = √(9·2) = 3√2.

Discriminant + quadratic formula — #38–44

38.How many real solutions: x2 − 8x + 16 = 0

Answer: 1 real solution (double root)
b² − 4ac = 64 − 64 = 0.

39.How many real solutions: −5x2 + x + 1 = 0

Answer: 2 real solutions
b² − 4ac = 1 − 4(−5)(1) = 1 + 20 = 21 > 0.

40.How many real solutions: 8x2 + 8x + 3 = 0

Answer: 0 real solutions
b² − 4ac = 64 − 96 = −32 < 0.

41.Solve: −5x2 + x + 1 = 0

Answer: x = (1 ± √21) / 10
a=−5, b=1, c=1. Disc=21. x = (−1 ± √21)/(−10) = (1 ∓ √21)/10. (Equivalent to ± since both signs included.)

42.Solve: x2 + 7x + 11 = 0

Answer: x = (−7 ± √5) / 2
Disc = 49 − 44 = 5.

43.Solve: 2x2 − 3x − 5 = 0

Answer: x = 5/2, x = −1
Disc = 9 + 40 = 49 = 7². x = (3 ± 7)/4 = 10/4 or −4/4. (Could also factor: (2x − 5)(x + 1) = 0.)

44.Solve: x2 + 3x − 20 = 0

Answer: x = (−3 ± √89) / 2
Disc = 9 + 80 = 89. √89 doesn't simplify.

Axis of symmetry & vertex — #45–48

Formula: x = −b/(2a), then plug back to get y. Vertex = (x, y).

45.f(x) = 3x2 − 18x + 7

Axis: x = 3 · Vertex: (3, −20)
x = 18/6 = 3. f(3) = 27 − 54 + 7 = −20.

46.f(x) = −2x2 + 8x − 3

Axis: x = 2 · Vertex: (2, 5)
x = −8/(−4) = 2. f(2) = −8 + 16 − 3 = 5.

47.f(x) = x2 + 6x + 8

Axis: x = −3 · Vertex: (−3, −1)
x = −6/2 = −3. f(−3) = 9 − 18 + 8 = −1.

48.f(x) = −x2 − 8x − 15

Axis: x = −4 · Vertex: (−4, 1)
x = 8/(−2) = −4. f(−4) = −16 + 32 − 15 = 1.

Graph quadratics & transformations — #49–56

49.Graph f(x) = 3(x − 2)2 − 4

Vertex (2, −4) · Opens UP (a=3 > 0) · Domain: all real numbers · Range: y ≥ −4
Vertex form (x − h)² shifts right h; +k shifts up k. a = 3 → narrower than parent.

50.Graph f(x) = (x − 3)2 + 2

Vertex (3, 2) · Opens UP · Domain: all real numbers · Range: y ≥ 2

51.Transform: A f(x) = x2 + 10 → B g(x) = x2 + 3

Answer: shifted DOWN 7 units.
k changed from +10 to +3 (10 − 3 = 7 down).

52.Transform: A f(x) = x2 + 7 → B g(x) = x2 − 4

Answer: shifted DOWN 11 units.
7 − (−4) = 11 down.

53.Transform: A f(x) = (x − 4)2 + 3 → B g(x) = (x − 3)2 + 3

Answer: shifted LEFT 1 unit.
Vertex moved from (4, 3) to (3, 3). h decreased by 1 → left.

54.Transform: A f(x) = 2(x + 1)2 + 3 → B g(x) = (x + 1)2 + 3

Answer: vertical compression (got wider) — a changed from 2 to 1.
Same vertex (−1, 3), but g is wider than f because |a| smaller.

55.Write a function: 5 LEFT and 8 DOWN from y = x2

Answer: f(x) = (x + 5)2 − 8
Left 5 → (x + 5)² (sign flips). Down 8 → − 8.

56.Write a function: 4 RIGHT and reflected over the x-axis from y = x2

Answer: f(x) = −(x − 4)2
Right 4 → (x − 4)². Reflection over x-axis → multiply by −1.

Word problems — #57–62

57.h(t) = −16t2 + 64t + 190. Initial height?

Answer: 190 feet
Initial = h(0) = 190. (The constant term IS the initial height.)

58.h(t) = −16t2 + 64t + 190. Maximum height?

Answer: 254 feet (at t = 2 sec)
Max at vertex t = −64 / (−32) = 2. h(2) = −64 + 128 + 190 = 254.

59.f(t) = −3t2 + 73t + 50 (hundreds of dollars). Initial amount?

Answer: $5,000
f(0) = 50, in hundreds → 50 × $100 = $5,000.

60.f(t) = −3t2 + 73t + 50. When is the value at a maximum?

Answer: t = 73/6 ≈ 12.17 months
Vertex t = −b/(2a) = −73/(−6) = 73/6.

61.Bottle rocket h(t) = −16t2 + 160t. Return to ground?

Answer: t = 10 seconds
Set h(t) = 0: −16t(t − 10) = 0 → t = 0 (launch) or t = 10 (lands). ⚠ Take the positive non-zero time.
(Note: the PDF prints this as "160t² − 16t" which is unusual physics; the standard projectile form −16t² + 160t gives t = 10. If the literal equation is meant, factor 16t(10t − 1) → t = 0 or 1/10.)

62.Foul ball f(t) = −16t2 + 64t. Time to reach the ground?

Answer: t = 4 seconds
−16t² + 64t = 0 → −16t(t − 4) = 0 → t = 0 (start) or t = 4 (lands).
