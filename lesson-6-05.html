6.05 — Function Composition

One function feeds into another. Two notations, one big idea — and the trick is reading which function goes first.

10 practice problems ~35 min Order matters!

Contents

A. What is composition?

Function composition means feeding the output of one function into another. Two equivalent notations:

  • f(g(x))   — read "f of g of x"
  • (f ∘ g)(x)   — read "f composed with g"

Both mean: first do g, then apply f to that result. The inside function runs first.

Visual: imagine a pipe. Input x → through g → g(x) comes out → into f → f(g(x)) comes out the other end.

B. f[g(a)] — plug in a number

To evaluate at a specific number: compute the inside first, then apply the outside function.

Worked example

f(x) = 4x + 21 and g(x) = 2x + 2. Find f[g(7)].

  1. Inside first: g(7) = 2(7) + 2 = 16
  2. Outside: f(16) = 4(16) + 21 = 64 + 21 = 85
Worked example

f(x) = 2x2 − 5 and g(x) = 3x − 7. Find f[g(4)].

  1. g(4) = 3(4) − 7 = 5
  2. f(5) = 2(25) − 5 = 45
Worked example

f(x) = 3x − 2 and g(x) = x2 − 1. Find f[g(5)].

  1. g(5) = 25 − 1 = 24
  2. f(24) = 3(24) − 2 = 70

C. f[g(x)] — algebraic composition

To compose algebraically, substitute the whole expression g(x) wherever you see x in f.

Worked example

f(x) = 6x + 11 and g(x) = x + 6. Find f[g(x)].

  1. f[g(x)] = f(x + 6)
  2. Wherever f had x, put (x + 6): 6(x + 6) + 11
  3. Distribute: 6x + 36 + 11 = 6x + 47
Worked example

f(x) = 7x + 13 and g(x) = x2 + 2. Find f[g(x)].

  1. f[g(x)] = f(x2 + 2) = 7(x2 + 2) + 13
  2. Distribute: 7x2 + 14 + 13 = 7x2 + 27

D. Order matters ⚠️

In general, f(g(x)) ≠ g(f(x)). Always check which function the question wants on the outside.
Why order matters

Let f(x) = x + 1 and g(x) = 2x.

  • f(g(x)) = f(2x) = 2x + 1
  • g(f(x)) = g(x + 1) = 2(x + 1) = 2x + 2

Different answers! Read the problem carefully.

E. Word problems: pick the right order

Pay attention to which action happens first. That's the inside function.

Discount then tax

Worked example

A bike is 30% off: c(p) = 0.7p (sale price from original p). Then sales tax of 12% on the discounted price: f(c) = 1.12c. What's the final price?

  • Discount happens first (innermost): c(p)
  • Then tax on top: f[c(p)]
  • f[c(p)] = 1.12 · (0.7p) = 0.784p

Selling tickets — money per hour

Worked example

f(x) = 0.5x dollars per ticket (x = tickets). g(x) = 6x tickets per hour (x = hours). What's money per hour?

  • Hours come in, tickets come out (g first), then dollars (f next).
  • f(g(x)) = 0.5(6x) = 3x dollars per hour

Biking — calories with trailer

Worked example

c(h) = 400h is calories burned biking (h = hours). t(c) = 2c doubles it when towing a trailer. Find calories per hour with the trailer.

  • Biking happens first (c), then doubling (t).
  • t[c(h)] = 2(400h) = 800h

F. Units of a composite function

The input units of the composite = the input units of the INNERMOST function. The output units = the output units of the OUTERMOST function. The middle unit "cancels" along the chain.

Worked example

s(t) makes signs per hour. w(h) is hours per week. Units of s(w(h))?

  • w takes weeks → hours
  • s takes hours → signs
  • So s(w(h)) goes weeks → signs. Units: signs per week.
Worked example

f(s) = flowers from s seeds. s(w) = seeds in w weeks. Units of f(s(w))?

  • weeks → seeds → flowers → flowers per week.

G. The squared-binomial trap

Watch out: when the outer function has x2, composing produces a squared binomial — don't drop the middle term.
Worked example

k(x) = 2x2 − 8 and p(x) = x − 4. Find (k ∘ p)(x).

  1. (k ∘ p)(x) = k(p(x)) = k(x − 4)
  2. k(x − 4) = 2(x − 4)2 − 8
  3. (x − 4)2 = x2 − 8x + 16 (perfect-square pattern, don't drop the −8x!)
  4. 2(x2 − 8x + 16) − 8 = 2x2 − 16x + 32 − 8 = 2x2 − 16x + 24

H. Practice (10 problems)

Problem 1

f(x) = 4x + 21, g(x) = 2x + 2. Find f[g(7)].

Show answer
85. g(7) = 16; f(16) = 64 + 21.
Problem 2

f(x) = 6x + 11, g(x) = x + 6. Find f[g(x)].

Show answer
6x + 47. 6(x + 6) + 11 = 6x + 36 + 11.
Problem 3

m(x) = 4x − 11, n(x) = x − 10. Find m[n(x)].

Show answer
4x − 51. 4(x − 10) − 11 = 4x − 40 − 11.
Problem 4

A dishwasher is 25% off: p(d) = 0.75d. Then 14% tax: c(p) = 1.14p. Final price?

Show answer
c[p(d)] = 0.855d. Discount first (innermost), then tax on top: 1.14(0.75d).
Problem 5

f(x) = 2x2 − 5, g(x) = 3x − 7. Find f[g(4)].

Show answer
45. g(4) = 5; f(5) = 2(25) − 5.
Problem 6

f(x) = 7x + 13, g(x) = x2 + 2. Find f[g(x)].

Show answer
7x2 + 27. 7(x2 + 2) + 13 = 7x2 + 14 + 13.
Problem 7

k(x) = 2x2 − 8, p(x) = x − 4. Find (k ∘ p)(x).

Show answer
2x2 − 16x + 24. k(x − 4) = 2(x − 4)2 − 8 = 2(x2 − 8x + 16) − 8.
Problem 8

P(w) = ½w + 1 is paintings as a function of weeks. J(y) is weeks per year. Function for paintings completed in a year?

Show answer
P[J(y)] = ½ · J(y) + 1. Year → weeks (J first) → paintings (P next).
Problem 9

s(t) is bracelets per hour. W(h) is hours per week. Units of s(W(h))?

Show answer
Bracelets per week. weeks → hours (W) → bracelets (s).
Problem 10

f(s) = 2s + 25 (flowers from s seeds), s(w) = 25w (seeds in w weeks). Find f(s(w)) and evaluate at w = 30.

Show answer
f(s(w)) = 50w + 25; f(s(30)) = 1,525 flowers. Substitute: f(25w) = 2(25w) + 25 = 50w + 25. At w = 30: 50(30) + 25 = 1525.

🔑 Key things to remember

  • Inside first: f(g(x)) means do g first, then f.
  • Order matters: f(g(x)) ≠ g(f(x)) in general. Re-read the problem to make sure you have the right order.
  • Word problems: the action that happens FIRST is the INNERMOST function (sale before tax → c is inner; biking before doubling → c is inner).
  • Units chain: composite input = innermost input; composite output = outermost output. Middle unit cancels.
  • Squared-binomial trap: if the outer function has x2, you'll get a perfect square (a±b)2 — keep the 2ab middle term.
