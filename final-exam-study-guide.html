Module 5 — Statistics

Reading data

  • Dot plot: stack dots above each value to show frequency.
  • Histogram: bars over intervals; height = frequency. Build the frequency table FIRST, then match the heights.
  • Box plot: shows five-number summary: min, Q1, median, Q3, max. The box spans Q1 to Q3 with the median line inside.

Measures of center & spread

  • Mean = sum ÷ count. Affected by outliers.
  • Median = middle value when sorted. Resistant to outliers.
  • Range = max − min. IQR = Q3 − Q1 (width of the box only, NOT max − min).
  • Standard deviation measures spread around the mean.
Choosing between mean and median: if the data is symmetric and no outliers → use the MEAN. If the data is skewed or has an outlier → use the MEDIAN. The median resists distortion.

Outliers (5.04)

Outlier rule: a value is an outlier if it's below Q1 − 1.5·IQR or above Q3 + 1.5·IQR.

Effect of removing an outlier: removing a value below the mean pulls the mean UP; removing a value above the mean pulls the mean DOWN. (The median barely shifts.)

Two-way frequency tables (5.05)

  • Joint frequency = a single inner cell.
  • Marginal frequency = a row or column TOTAL.
  • Marginal relative = row/column total ÷ grand total.
  • Conditional relative (row) = cell ÷ ROW total. Each row sums to 1.
  • Conditional relative (column) = cell ÷ COLUMN total. Each column sums to 1.
Pick the denominator carefully. "Of dog owners, what % own cats?" → divide by dog-owner ROW total. "Of cat owners, what % own dogs?" → divide by cat-owner COLUMN total. Same cell, different denominators → different answers.

Scatter plots, LOBF, residuals (5.06)

  • Line of best fit: straight line through the middle of the data.
  • Slope = rate of change in context (e.g., "$ per item").
  • y-intercept = value when x = 0 (the starting value in context).
  • Residual = actual − predicted. Small residuals → good fit.
"Good fit" criterion: residuals should sum to ≈ 0 with a random scatter — NOT "every residual must be small." A line where residuals are 40, −10, 40, −10, 40, −20 (sum = 80) is a BAD fit.

Correlation vs. causation (5.07)

  • r ranges from −1 to +1. Sign matches slope, magnitude matches "how close to the line."
  • |r| near 1 = strong; near 0 = weak/none.
  • Correlation ≠ causation. Strong r only means the variables move together; a third "confounding variable" might explain both.

⭐ Average rate of change (recurring weak spot)

Average rate of change from x₁ to x₂ = (y₂ − y₁) / (x₂ − x₁)
The trap Neil hit twice: dividing by Δx is required. If the question gives "profit at hour 2 = $30, at hour 6 = $98," the answer is (98 − 30) / (6 − 2) = 68/4 = $17 per hour, NOT $68. Always divide AND include units.

Module 6 — Polynomial Operations

Classifying (6.01)

  • Term count names: 1 = monomial, 2 = binomial, 3 = trinomial, 4+ = polynomial.
  • Degree names: 0 = constant, 1 = linear, 2 = quadratic, 3 = cubic, 4 = quartic.
  • Standard form = terms in DESCENDING degree order.
Multi-variable degree: ADD the exponents in each term. 3y3x has degree 3 + 1 = 4, not 3.
Not a polynomial: variable in a denominator (or negative exponent), under a root (or fractional exponent), or in the exponent (e.g., 2x).

Add/subtract + closure (6.02)

  • Combine like terms (same variables, same exponents).
  • (f + g)(a) = f(a) + g(a); (f − g)(a) = f(a) − g(a).
  • Closure: +, −, × of polynomials always give a polynomial. ÷ does not.
Subtracting polynomials: distribute the minus to EVERY term in the second polynomial. (5x² + 2x − 6) − (3x² − 6x + 2) = 5x² + 2x − 6 − 3x² + 6x − 2 = 2x² + 8x − 8. The #1 mistake is forgetting to flip the +6x and the +2.
"A subtracted FROM B" = B − A, not A − B.
Profit = revenue − cost. When a word problem subtracts two functions, name the result (profit, deficit) — don't write "cost."

Exponent rules (6.03)

Apply power-of-a-product to EVERY factor — including the coefficient. (3x)4 = 81x4, not 3x4.

Multiplying polynomials (6.04)

  • Distribute a monomial across each term.
  • FOIL two binomials: F, O, I, L.
  • Difference of squares: (a − b)(a + b) = a2 − b2 (no middle term).
  • Perfect square: (a ± b)2 = a2 ± 2ab + b2. Don't drop the 2ab middle term.
The perfect-square trap: (3x − 8)2 = 9x2 − 48x + 64, NOT 9x2 − 64 and NOT 9x2 + 64.

Function composition (6.05)

  • f(g(x)) means do g first, then f. INSIDE function runs first.
  • f(g(x)) ≠ g(f(x)) in general — order matters.
  • Word problems: the action that happens FIRST is the INNERMOST function. ("30% off then $5 coupon" → discount c is inside, coupon g is outside: g(c(p)).)
  • Units chain: composite input units = innermost input; output units = outermost output. The middle unit cancels.

Module 7 — Factoring & Graphing Polynomials

Factoring decision tree (memorize)

  1. Always pull out the GCF first.
  2. Look at how many terms are left:
    • 2 terms → try difference of squares: a2 − b2 = (a − b)(a + b).
    • 3 terms → factor the trinomial.
    • 4 terms → try factoring by grouping.
  3. Check each piece — can anything factor further?

Factoring trinomials

When a = 1: x2 + bx + c → find two numbers multiplying to c, adding to b. Answer: (x + p)(x + q).

When a ≠ 1 (AC method): find two numbers multiplying to a·c, adding to b. Split bx into those two terms, then factor by grouping.

Graphing polynomials (7.05)

  • Roots / zeros / x-intercepts — factor f(x), set each factor to 0, solve.
  • End behavior — controlled by leading term.
    • Even degree: both ends same direction. Odd degree: opposite ends.
    • Positive leading coefficient: right end UP. Negative: right end DOWN.
  • Multiplicity: if (x − r)n appears, root r has multiplicity n. Odd multiplicity = crosses; even multiplicity = touches and bounces.

Module 8 — Quadratic Functions

The 3 forms

Factoreda(x − r1)(x − r2)roots r1, r2

The parabola

  • Vertex x-coordinate: x = −b / (2a). Plug back in for y.
  • Axis of symmetry: x = −b / (2a).
  • y-intercept: f(0) = c.
  • If a > 0 → opens UP, vertex is a minimum.
  • If a < 0 → opens DOWN, vertex is a maximum.

3 ways to solve ax2 + bx + c = 0

  1. Factor if the quadratic factors. Zero product property: set each factor to 0.
  2. Square root if there's no middle x. Isolate x², take ±√.
  3. Quadratic formula (always works):
    x = (−b ± √(b2 − 4ac)) / (2a)

The discriminant: b2 − 4ac

DiscriminantReal solutions

Vertex form & transformations

For f(x) = a(x − h)2 + k: vertex is (h, k). Compared to y = x2:

  • h shifts RIGHT (note: the sign in (x − h) flips — (x − 5) shifts right 5).
  • k shifts UP.
  • |a| stretches vertically; if a < 0, the parabola flips (opens down).

Word problems

Projectile height: typical equation h(t) = −16t2 + v0t + h0 (feet, seconds).

  • Max height → vertex t = −b/(2a) = v0/32. Then plug back to get h.
  • Hits ground → set h(t) = 0 and solve (use quadratic formula). Take only the positive t.
±√ has two answers — keep both. Common drop: x² = 49 → x = ±7, not just 7.

📋 Day-of-exam routine

  1. Bring: calculator (the one allowed), pencils, ID, water. Photo ID even if it's a known test center.
  2. Before you walk in (5 min): skim THIS page top to bottom. Don't try to learn anything new — just refresh.
  3. First pass: answer every question you can do quickly. Skip and mark the hard ones — don't burn time getting stuck.
  4. Second pass: come back to the marked ones with whatever time remains.
  5. Read carefully: "subtracted FROM" reverses order, "of cat owners" sets the denominator, "average rate of change" needs ÷Δx with units. Most mistakes come from misreading, not misunderstanding.
  6. Show work where space allows. Even on MC, writing the steps helps catch sign errors.
  7. If you get stuck: try the next one. Coming back later with a clear head usually unsticks you.
  8. Last 2 minutes: make sure every question has SOME answer. Educated guess beats blank.
