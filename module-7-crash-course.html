Module 7 — Factoring & Graphing Polynomials (Crash Course)

The whole module in one page. Factoring is undoing multiplication — every problem boils down to recognizing one of 4 patterns and applying it. Learn to identify the pattern first, then the method follows.

5 sub-topics ~45 min For the final
The factoring decision tree (memorize this):
  1. Always try GCF first.
  2. If 2 terms → try difference of squares: a² − b² = (a−b)(a+b).
  3. If 3 terms → try factoring trinomials (find two numbers).
  4. If 4 terms → try factoring by grouping.

A. 7.01 — Greatest Common Factor (GCF)

The GCF of a polynomial is the largest monomial that divides every term. Factor it out and write the polynomial as GCF · (what's left).

How to find the GCF

  1. For coefficients: take the largest number that divides all of them.
  2. For each variable: take the LOWEST power that appears in every term.
Worked example

Factor 12x3y + 18x2y2 − 6xy.

  • Coefficients 12, 18, 6 → GCF = 6.
  • x appears as x³, x², x¹ → lowest power x¹.
  • y appears as y¹, y², y¹ → lowest power y¹.
  • GCF = 6xy.
  • Divide each term by 6xy: 6xy(2x2y + 3xy − 1).
Always check first: after pulling out a GCF, look at what's inside the parentheses — it might factor further (by one of the patterns below).

B. 7.02 — Factoring by grouping (4 terms)

When you have 4 terms, group them in pairs, factor each pair, and look for a common binomial.

Worked example

Factor x3 + 3x2 + 2x + 6.

  1. Group: (x3 + 3x2) + (2x + 6)
  2. Factor each group: x2(x + 3) + 2(x + 3)
  3. Both pieces have (x + 3) — factor it out: (x + 3)(x2 + 2)
Worked example with a negative

Factor 2x3 − 6x2 + 5x − 15.

  1. Group: (2x3 − 6x2) + (5x − 15)
  2. Factor each: 2x2(x − 3) + 5(x − 3)
  3. Factor out (x − 3): (x − 3)(2x2 + 5)
If the binomials don't match after step 2, the second group may need a negative sign factored out. Example: x³ − 3x² − 4x + 12 → x²(x − 3) + (−4)(x − 3) = (x − 3)(x² − 4) = (x − 3)(x − 2)(x + 2).

C. 7.03 — Factoring trinomials when a = 1

For x2 + bx + c: find two numbers that multiply to c AND add to b. Write the answer as (x + p)(x + q).

Worked example

Factor x2 + 7x + 12.

  • Need two numbers: multiply to 12, add to 7.
  • Pairs of 12: 1·12, 2·6, 3·4. Which adds to 7? 3 + 4 = 7 ✓
  • Answer: (x + 3)(x + 4).
Worked example with negatives

Factor x2 − 5x + 6.

  • Multiply to +6 (positive), add to −5 (negative) → both numbers are negative.
  • Pairs of 6: −1·−6, −2·−3. Which adds to −5? −2 + −3 = −5 ✓
  • Answer: (x − 2)(x − 3).
Worked example with c < 0

Factor x2 + 2x − 15.

  • Multiply to −15, add to +2 → one positive, one negative.
  • Pairs: 5·−3 (5 + −3 = 2) ✓
  • Answer: (x + 5)(x − 3).
Sign cheat sheet:
  • c > 0, b > 0 → both factors are positive (+, +)
  • c > 0, b < 0 → both factors are negative (−, −)
  • c < 0 → factors have opposite signs (+, −); the larger absolute value gets b's sign

D. 7.03 — Factoring trinomials when a ≠ 1 (AC method)

For ax2 + bx + c with a ≠ 1: find two numbers that multiply to a·c AND add to b. Use them to split bx, then factor by grouping.

Worked example

Factor 2x2 + 7x + 3.

  1. a·c = 2·3 = 6. Need two numbers: multiply to 6, add to 7. → 1 and 6.
  2. Split 7x as 1x + 6x: 2x2 + 1x + 6x + 3.
  3. Factor by grouping: x(2x + 1) + 3(2x + 1) = (2x + 1)(x + 3).
  4. Answer: (2x + 1)(x + 3).
Worked example

Factor 3x2 − 10x + 8.

  1. a·c = 3·8 = 24. Two numbers: multiply to 24, add to −10 → −4 and −6.
  2. Split: 3x2 − 4x − 6x + 8.
  3. Group: x(3x − 4) − 2(3x − 4) = (3x − 4)(x − 2).
  4. Answer: (3x − 4)(x − 2).

E. 7.04 — Difference of perfect squares

Pattern: a2 − b2 = (a − b)(a + b). Recognize it by two terms separated by a minus, both perfect squares.

Examples

x2 − 9 = (x − 3)(x + 3)    4x2 − 25 = (2x − 5)(2x + 5)

16y2 − 49 = (4y − 7)(4y + 7)    x4 − 16 = (x2 − 4)(x2 + 4) = (x − 2)(x + 2)(x2 + 4)

Watch for: a SUM of squares (a² + b²) does NOT factor over the real numbers — it stays as is. Only the difference factors.

F. 7.05 — Graphing polynomial functions

Roots / zeros / x-intercepts

The roots of a polynomial are the x-values where it equals 0 — i.e., the x-intercepts of the graph. Factor → set each factor to 0 → solve.

Worked example

Find the roots of f(x) = x2 − x − 6.

  1. Factor: x² − x − 6 = (x − 3)(x + 2).
  2. Set each factor = 0: x − 3 = 0 → x = 3. x + 2 = 0 → x = −2.
  3. Roots: x = 3 and x = −2.

End behavior

The leading term (the highest-degree term) controls the end behavior.

DegreeLeading coeffLeft endRight end
EvenPositive↑↑
EvenNegative↓↓
OddPositive↓↑
OddNegative↑↓
Memory aid: even-degree polynomials look like parabolas (both ends same direction). Odd-degree polynomials look like an "S" or backward-S (ends go opposite directions).

Multiplicity

If a factor (x − r) appears n times, the root x = r has multiplicity n.

  • Odd multiplicity (1, 3, 5…): graph CROSSES the x-axis at that root.
  • Even multiplicity (2, 4…): graph TOUCHES and bounces off the x-axis (doesn't cross).

G. Practice (15 problems)

Problem 1 · GCF

Factor: 10x3 − 15x2 + 5x.

Show answer
5x(2x2 − 3x + 1). Then check the trinomial — it factors further: 5x(2x − 1)(x − 1).
Problem 2 · GCF

Factor: 12x2y − 8xy2 + 4xy.

Show answer
4xy(3x − 2y + 1). Coeffs GCF 4; x lowest x¹; y lowest y¹.
Problem 3 · Grouping

Factor: x3 + 2x2 + 5x + 10.

Show answer
(x + 2)(x2 + 5). Group: x²(x + 2) + 5(x + 2).
Problem 4 · Grouping

Factor: x3 − 4x2 + 3x − 12.

Show answer
(x − 4)(x2 + 3). Group: x²(x − 4) + 3(x − 4).
Problem 5 · Trinomial (a=1)

Factor: x2 + 9x + 20.

Show answer
(x + 4)(x + 5). 4·5 = 20, 4+5 = 9.
Problem 6 · Trinomial (a=1)

Factor: x2 − 8x + 15.

Show answer
(x − 3)(x − 5). Both negative (c > 0, b < 0): −3 · −5 = 15, −3 + −5 = −8.
Problem 7 · Trinomial (a=1)

Factor: x2 + 3x − 28.

Show answer
(x + 7)(x − 4). Opposite signs (c < 0): 7 · −4 = −28, 7 + −4 = 3.
Problem 8 · Trinomial (a≠1)

Factor: 3x2 + 11x + 6.

Show answer
(3x + 2)(x + 3). a·c = 18; need 9 + 2 = 11 → split: 3x² + 9x + 2x + 6 → 3x(x + 3) + 2(x + 3).
Problem 9 · Trinomial (a≠1)

Factor: 2x2 − 7x + 6.

Show answer
(2x − 3)(x − 2). a·c = 12; need −3 + −4 = −7 → split: 2x² − 3x − 4x + 6 → x(2x − 3) − 2(2x − 3).
Problem 10 · Difference of squares

Factor: x2 − 49.

Show answer
(x − 7)(x + 7). 49 = 7².
Problem 11 · Difference of squares

Factor: 9x2 − 64.

Show answer
(3x − 8)(3x + 8). 9x² = (3x)², 64 = 8².
Problem 12 · Combined (GCF + DOS)

Factor completely: 2x3 − 18x.

Show answer
2x(x − 3)(x + 3). GCF 2x first → 2x(x² − 9), then difference of squares.
Problem 13 · Roots

Find the roots of f(x) = x2 + 5x − 14.

Show answer
x = −7 and x = 2. Factor: (x + 7)(x − 2) = 0 → x = −7 or x = 2.
Problem 14 · End behavior

Describe the end behavior of f(x) = −2x3 + 5x.

Show answer
Left end ↑, right end ↓. Odd degree (3), negative leading coefficient → backward-S shape.
Problem 15 · Multiplicity

Where does f(x) = (x − 2)2(x + 1) cross or touch the x-axis?

Show answer
Touches at x = 2 (multiplicity 2, even — bounces), crosses at x = −1 (multiplicity 1, odd — crosses).
