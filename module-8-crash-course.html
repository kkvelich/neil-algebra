Module 8 — Quadratic Functions (Crash Course)

Quadratics in one page. Every quadratic looks like ax2 + bx + c and graphs as a parabola. The skills: graph it, find roots three different ways, and translate between standard / vertex / factored forms.

5 sub-topics ~50 min For the final
3 ways to solve a quadratic (pick the easiest):
  1. Factor if it factors easily (whole-number roots). Set each factor to 0.
  2. Square root if there's no middle x term (just ax² + c = 0). Isolate, take ±√.
  3. Quadratic formula always works: x = (−b ± √(b² − 4ac)) / (2a).

Same parabola, three views. The form you want depends on what the question asks. Convert between them when needed.

B. The parabola — vertex, axis, intercepts

Every quadratic graph is a parabola: a U-shape. If a > 0 it opens up; if a < 0 it opens down.

  • Vertex: the highest or lowest point. x-coordinate = −b/(2a) (from standard form), then plug back in to get y.
  • Axis of symmetry: the vertical line through the vertex, x = −b/(2a).
  • y-intercept: set x = 0 → f(0) = c.
  • x-intercepts (roots): set f(x) = 0 and solve.
  • Maximum vs minimum: a > 0 → vertex is a MINIMUM; a < 0 → vertex is a MAXIMUM.
Worked example

Find the vertex of f(x) = 2x2 − 8x + 5.

  • a = 2, b = −8 → x-coordinate = −(−8)/(2·2) = 8/4 = 2.
  • y-coordinate: f(2) = 2(4) − 8(2) + 5 = 8 − 16 + 5 = −3.
  • Vertex: (2, −3). Axis of symmetry: x = 2. a > 0 → opens up, so this is a MIN.

C. Solving by factoring

If the quadratic factors with nice integers, this is fastest. Use everything you learned in Module 7.

Worked example

Solve x2 + 5x − 14 = 0.

  1. Factor: (x + 7)(x − 2) = 0.
  2. Zero product property: x + 7 = 0 or x − 2 = 0.
  3. Solutions: x = −7 or x = 2.
Zero product property: if A·B = 0, then A = 0 or B = 0 (or both). This is why factoring solves equations.

D. Solving by square root

When there's NO middle x term (only ax² and a constant), isolate x² and take ±√ of both sides.

Worked example

Solve 3x2 − 48 = 0.

  1. Add 48: 3x² = 48.
  2. Divide by 3: x² = 16.
  3. Take ±√: x = ±4. (Don't forget the negative root!)
  4. Solutions: x = 4 or x = −4.
Worked example — vertex form

Solve (x − 3)2 = 25.

  1. Take ±√: x − 3 = ±5.
  2. Add 3: x = 3 ± 5 → x = 8 or x = −2.

E. The quadratic formula + discriminant

Memorize this:
For ax2 + bx + c = 0:
x = (−b ± √(b2 − 4ac)) / (2a)
Worked example

Solve 2x2 + 3x − 5 = 0 with the formula.

  1. a = 2, b = 3, c = −5.
  2. b² − 4ac = 9 − 4(2)(−5) = 9 + 40 = 49.
  3. x = (−3 ± √49) / (2·2) = (−3 ± 7) / 4.
  4. Two solutions: x = (−3 + 7)/4 = 1, and x = (−3 − 7)/4 = −5/2.
  5. Solutions: x = 1 or x = −5/2.

The discriminant: b² − 4ac

Just the part under the square root. It tells you how many real solutions exist without finishing the formula.

F. Completing the square

Converts standard form → vertex form. Used when the question asks for the vertex but the quadratic isn't already there.

Worked example (a = 1)

Rewrite x2 + 6x + 5 in vertex form.

  1. Take half of b (= 6/2 = 3), square it (= 9).
  2. Add and subtract 9 inside: x² + 6x + 9 − 9 + 5.
  3. Group the perfect square: (x + 3)² − 4.
  4. Vertex form: (x + 3)2 − 4. Vertex: (−3, −4).
Shortcut for vertex form from standard form: if you only need the vertex, use x = −b/(2a) and y = f(x). Completing the square is for when the question wants the FORM, not just the point.

G. Transformations: f(x) = a(x − h)2 + k

Vertex form is also a transformation of the parent function y = x²:

  • h shifts the parabola RIGHT by h (note: (x − h) shifts right by h, not left).
  • k shifts the parabola UP by k.
  • a stretches vertically (|a| > 1 = narrower; 0 < |a| < 1 = wider). If a < 0, the parabola also flips (opens down).
Worked example

Describe f(x) = −2(x − 4)2 + 7 as a transformation of y = x².

  • a = −2: stretched (narrower) AND flipped (opens down).
  • h = 4: shifted RIGHT 4.
  • k = 7: shifted UP 7.
  • Vertex: (4, 7), opens down, so the vertex is a MAXIMUM at y = 7.

H. Word problems

Projectile / height (the classic): h(t) = −16t² + v₀t + h₀

Standard physics setup (feet/seconds): −16 is half of gravity, v₀ is initial upward velocity (ft/s), h₀ is initial height (ft).

Worked example

A ball is launched from a 5-ft platform at 64 ft/s upward: h(t) = −16t2 + 64t + 5. When does it reach max height? What's the max height?

  1. Vertex t-coordinate: t = −b/(2a) = −64/(2·(−16)) = 64/32 = 2 seconds (time of max).
  2. Max height: h(2) = −16(4) + 64(2) + 5 = −64 + 128 + 5 = 69 feet.
Worked example — when does it hit the ground?

Same h(t). Set h(t) = 0 and solve.

  1. −16t² + 64t + 5 = 0. Use the quadratic formula.
  2. a = −16, b = 64, c = 5. b² − 4ac = 4096 + 320 = 4416.
  3. t = (−64 ± √4416) / (−32) ≈ (−64 ± 66.45) / (−32).
  4. Take the positive root: t ≈ 4.08 seconds. (The negative root is meaningless here.)

Area problems

Worked example

A rectangular garden has length (x + 4) and width (x + 2). The area is 24 sq ft. Find x.

  1. Area = (x + 4)(x + 2) = 24 → x² + 6x + 8 = 24 → x² + 6x − 16 = 0.
  2. Factor: (x + 8)(x − 2) = 0 → x = −8 or x = 2.
  3. Length must be positive → x = 2.

I. Practice (15 problems)

Problem 1 · Vertex

Find the vertex of f(x) = x2 − 6x + 11.

Show answer
(3, 2). x = −(−6)/(2·1) = 3; f(3) = 9 − 18 + 11 = 2.
Problem 2 · Axis

Axis of symmetry for f(x) = −x2 + 4x − 7?

Show answer
x = 2. x = −4/(2·−1) = 2.
Problem 3 · Factor

Solve x2 − 7x + 12 = 0.

Show answer
x = 3 or x = 4. (x − 3)(x − 4) = 0.
Problem 4 · Factor

Solve 2x2 + 5x − 3 = 0.

Show answer
x = −3 or x = 1/2. Factor with AC method: (2x − 1)(x + 3) = 0.
Problem 5 · Square root

Solve x2 = 81.

Show answer
x = ±9. Both ±! Don't drop the negative.
Problem 6 · Square root

Solve (x + 2)2 = 49.

Show answer
x = 5 or x = −9. x + 2 = ±7 → x = −2 ± 7.
Problem 7 · Quadratic formula

Solve x2 + 3x − 10 = 0 using the quadratic formula.

Show answer
x = 2 or x = −5. a=1, b=3, c=−10. b² − 4ac = 9 + 40 = 49. x = (−3 ± 7)/2.
Problem 8 · Quadratic formula

Solve 2x2 − 4x + 1 = 0 (the roots are not integers).

Show answer
x = (4 ± √8)/4 = 1 ± (√2)/2. b² − 4ac = 16 − 8 = 8.
Problem 9 · Discriminant

How many real solutions does x2 + 4x + 9 = 0 have?

Show answer
0 real (the discriminant is negative). b² − 4ac = 16 − 36 = −20 < 0. The graph never crosses the x-axis.
Problem 10 · Completing the square

Write x2 − 8x + 3 in vertex form.

Show answer
(x − 4)2 − 13. Half of −8 = −4; squared = 16. x² − 8x + 16 − 16 + 3 = (x − 4)² − 13. Vertex (4, −13).
Problem 11 · Vertex form

What's the vertex of f(x) = 3(x + 2)2 − 5?

Show answer
(−2, −5). Vertex form a(x − h)² + k: h = −2 (the SIGN flips), k = −5.
Problem 12 · Transformations

Describe how f(x) = −(x − 3)2 + 4 transforms y = x².

Show answer
Flipped down, shifted right 3, up 4. a = −1 flips (opens down); vertex moves to (3, 4) which is the maximum.
Problem 13 · Word — height

A ball: h(t) = −16t2 + 48t + 4. Max height?

Show answer
40 feet (at t = 1.5 s). t = −48/(2·−16) = 1.5. h(1.5) = −36 + 72 + 4 = 40.
Problem 14 · Word — area

Rectangle with length (x + 3) and width x has area 40. Find x.

Show answer
x = 5. x(x + 3) = 40 → x² + 3x − 40 = 0 → (x + 8)(x − 5) = 0. Take positive root.
Problem 15 · Graph

Describe f(x) = 2x2 − 12x + 10: opens up or down, vertex, axis of symmetry, y-intercept.

Show answer
Opens UP, vertex (3, −8), axis x = 3, y-intercept 10. a = 2 > 0 → up. x_vertex = 12/(2·2) = 3. f(3) = 18 − 36 + 10 = −8. y-int = c = 10.
