B. Product rule — same base, ADD exponents

When you multiply powers with the same base, keep the base and add the exponents.

Examples

d3 · d5 = d3+5 = d8

(2x)(4y) = 8xy — multiply the coefficients (2·4=8), keep distinct variables together.

(3x2y3)(2x5y2z3) = 6x7y5z3 — multiply coefficients, add exponents on each variable separately.

Different bases stay separate: x · y stays x · y. You can only add exponents when the BASES match.

C. Quotient rule — SUBTRACT exponents

Same base, division? Subtract the bottom exponent from the top.

Examples

x7 / x3 = x7−3 = x4

(g5h4) / (g2h3) = g5−2h4−3 = g3h — subtract for each variable separately.

D. Power of a power — MULTIPLY exponents

A power raised to another power? Multiply the exponents.

Examples

(b5)4 = b5·4 = b20

(x3)2 = x6

Don't confuse with the product rule: b5 · b4 = b9 (add) vs. (b5)4 = b20 (multiply). The parentheses make all the difference.

E. Power of a product — apply to EACH factor

An entire product raised to a power? Distribute the exponent to every factor (including the coefficient).

Examples

(3x)4 = 34·x4 = 81x4 — apply to the 3 AND the x.

(x2y)2 = x4y2 — apply to BOTH variables.

(9x3y2)2 = 92·x6·y4 = 81x6y4

The #1 mistake: forgetting the coefficient. (3x)4 ≠ 3x4. The 3 also gets raised to the 4th power.

F. Power of a quotient — apply to top AND bottom

A whole fraction raised to a power? Distribute the exponent to the numerator and the denominator.

Examples

(2b/c)3 = 23·b3 / c3 = 8b3/c3

(x2/y4)3 = x6/y12

G. Negative exponents — flip across the bar

A negative exponent means "take the reciprocal and make the exponent positive." If a variable with a negative exponent is in the numerator, move it to the denominator. If it's already in the denominator, move it up to the numerator. The exponent's sign flips when you move it.

Examples

x−2 = 1/x2

4m / n−3 = 4m · n3 = 4mn3 — the n−3 on the bottom moves up as n3.

16 / n−3 = 16n3

3b / a−2 = 3b · a2 = 3a2b

H. Zero exponent — anything (≠ 0) to the 0 = 1

Any nonzero base raised to the 0 power equals 1.

Examples

70 = 1    x0 = 1 (when x ≠ 0)    (3xy)0 = 1

I. Combining multiple rules

Tough problems chain several rules. Tackle them one piece at a time, applying the appropriate rule per step.

Worked example

(4xy)(2x2y)(3xy)3

  1. Handle the power of a product first: (3xy)3 = 27x3y3
  2. Now multiply all three monomials (product rule): (4xy)(2x2y)(27x3y3)
  3. Coefficients: 4·2·27 = 216
  4. x exponents: 1 + 2 + 3 = 6
  5. y exponents: 1 + 1 + 3 = 5
  6. Result: 216x6y5
Worked example

(5xy5)2(y3)4

  1. Each piece: (5xy5)2 = 25x2y10
  2. (y3)4 = y12
  3. Multiply: 25x2y10 · y12 = 25x2y22

J. Practice (10 problems)

Problem 1

Find the product: (2x)(4y).

Show answer
8xy. Coefficients: 2·4 = 8; variables x and y stay separate.
Problem 2

Simplify: d3 · d5.

Show answer
d8. Same base → add exponents: 3 + 5 = 8.
Problem 3

Simplify: (b5)4.

Show answer
b20. Power of a power → multiply: 5 · 4 = 20.
Problem 4

Simplify: (9x3y2)2.

Show answer
81x6y4. Apply the 2 to EACH factor: 92=81, (x3)2=x6, (y2)2=y4.
Problem 5

Simplify: (3x)4.

Show answer
81x4. 34=81 (don't forget the coefficient), x4.
Problem 6

Simplify: (x2y)2.

Show answer
x4y2. (x2)2=x4, y2.
Problem 7

Simplify: (4xy)(2x2y)(3xy)3.

Show answer
216x6y5. First (3xy)3=27x3y3. Then coefficients 4·2·27 = 216; x: 1+2+3 = 6; y: 1+1+3 = 5.
Problem 8

Simplify: (2b/c)3.

Show answer
8b3/c3. Apply the 3 to top AND bottom: 23=8, b3, c3.
Problem 9

Simplify: (g5h4) / (g2h3).

Show answer
g3h. Subtract for each base: g5−2=g3; h4−3=h1=h.
Problem 10

Simplify: 16 / n−3.

Show answer
16n3. The negative exponent in the denominator flips up to a positive in the numerator: 16/n−3 = 16·n3.

🔑 Key things to remember

  • Same base, multiply: ADD exponents. Same base, divide: SUBTRACT.
  • Power of a power: MULTIPLY exponents.
  • Power of a product/quotient: apply the exponent to EVERY factor — including the coefficient!
  • Negative exponent: move across the bar (numerator ↔ denominator), drop the negative.
  • Different bases stay separate. Coefficients combine; variables track their own exponent.
